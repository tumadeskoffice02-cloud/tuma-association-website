# Membership workflow and screens

## Applicant
- Sign up/sign in using secure authentication.
- Complete the application form.
- See own application status: Pending, Under Review, Approved, or Rejected.
- If approved, open member profile and digital card.

## Secretary / reviewer
- Open pending applications.
- Review application details.
- Mark Under Review.
- Add a short internal review note.
- Submit recommendation or make a decision only if the association grants that permission.

## Authorized approving executive
- Approve or reject with a recorded reason.
- On approval, create the member record and assign the next unique membership number using a server-side transaction.
- Notify applicant through a configured email service if enabled.

## Member ID
- TUMA logo, member name, unique membership number, status, and optional photo.
- QR code contains only a random verification token or a URL using an opaque identifier.
- Verification page reveals only the minimum approved public fields and current status.

## Before going live
TUMA must confirm eligibility criteria, the person/role allowed to approve, membership numbering convention, privacy notice, data retention policy, and whether member photos are required.
